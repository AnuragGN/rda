Laravel 8 : Queueing By Default

Other option to set queue individually was like below :

Mail::to($request->user())->cc($moreUsers)->bcc($evenMoreUsers)->queue(new OrderShipped($order));

But in future we may also required sending urgent email directly without Queue.
For that we can follow this link : Synchronous Dispatching

Further the main command to monitor and execute the Queue jobs is :
"php artisan queue:work"
